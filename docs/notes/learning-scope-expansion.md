# 메모 — 학습 범위 확장 방향 (범위 밖, 반영 안 함)

> 현재 개선 프로젝트에는 **반영하지 않는다.** 데이터셋이 2020년 1~3월 코로나 국면 한 구간에만 묶여 있어
> "특정 사건 대응"은 학습되지만 "일반적인 뉴스 판단력"은 잘 안 길러진다는 문제의식에 대한 아이디어 메모.

## 문제

- 시드가 단일 국면(코로나 폭락기). 유저가 이 구간을 반복하면 "이 시기엔 항공 팔고 바이오 사면 된다"를 **암기**하게 됨.
- 이벤트 정답지가 대형 이벤트 몇 건에만 존재 → 나머지 일상 뉴스 판단은 사후 채점이 안 됨 (S-2).
- 새 구간을 넣으려면 뉴스·시세·이벤트·정답지를 수작업 큐레이션 (S-3).

## 방향 아이디어

### 1. 시나리오 팩 구조
`{기간, 종목군, 뉴스셋, 이벤트셋, 시세}` 를 하나의 "팩"으로 묶고 유저가 선택.
- 2020 코로나 폭락·회복 / 2022 금리인상·인플레 / 2023 AI 랠리 / 2018 미중 무역분쟁 / 평상시 박스권
- 도메인 변경 최소: `scenario` 엔티티 추가, `news_article`·`stock_price`·`event_stock_impact`에 `scenario_id` FK. 시뮬레이션 세션이 팩 하나에 종속.

### 2. 난이도 커리큘럼
명확한 이벤트(팬데믹) → 애매한 신호(실적 서프라이즈, 가이던스 변경) → 노이즈 큰 평상시.
틀린 **유형**을 다시 출제(오답 노트 / spaced repetition).

### 3. 유형 일반화 학습
개별 사건 암기가 아니라 패턴 인식: "유가 급락 → 항공 원가 수혜", "방역 강화 → 여행·면세 타격", "금리 인상 → 성장주 할인".
이벤트 타입(`EventType`)별 사후 요약 카드를 리포트에 추가.

### 4. 사후 피드백 루프를 전체 뉴스로 확대 (S-2 해결과 연결)
모든 뉴스에 대해 "판단 시점 이후 N일 실제 주가 변화"를 계산해 개별 뉴스 채점.
→ `event_stock_impact`(수작업 정답지) 의존을 줄이고, 실제 시세에서 정답을 파생.

### 5. 데이터 파이프라인 (S-3 근본 해결)
수작업 큐레이션 대신 인제스천 파이프라인:
- 뉴스 수집(API) → AI 서비스로 감성 자동 라벨링 → 관련 종목 매핑
- 시세 수집(API) → 비정상 수익률 구간 자동 탐지 → 이벤트 후보 생성
- 사람은 이벤트 후보 검수만
→ 시나리오 팩을 반자동 생성. 이건 별도 프로젝트 규모.

### 6. 최근 모드 (paper trading)
최근 뉴스 + 지연(15분~1일) 실제 시세로 라이브 페이퍼 트레이딩. 데이터 파이프라인(5) 선행 필요.

## 요약

MVP는 단일 시나리오(2020 Q1)로 빠르게 검증했으나 학습 효과가 사건 암기에 그치는 한계가 있다.
시나리오 팩 구조 + 실제 시세 기반 사후 채점으로 일반화 학습을 설계하는 것이 다음 단계.
BE 개선 범위 밖이라 이 문서로만 기록한다.
