# ADR 0001 — 개선 작업의 문서화·워크플로

- 상태: 채택
- 날짜: 2026-09-09

## 배경

`newspin-be`를 자소서·면접에서 설명 가능한 수준으로 고도화한다. 결과물뿐 아니라 **과정**(문제 발견 → 원인 → 대안 검토 → 구현 → 검증 → 회고)이 남아야 한다.

## 결정

1. **문서 원본은 레포 `docs/`의 Markdown.** Notion은 정리본 미러로만 사용.
2. **작업 단위 = 항목 1개.** 항목마다 브랜치 1개, PR 1개(본인 레포 `develop` 대상), `docs/improvements/NN-*.md` 1개.
3. **브랜치 접두사**: `feat/ fix/ perf/ refactor/ test/ chore/`.
4. **커밋 분리**: 순수 리팩토링과 동작 변경을 같은 커밋에 섞지 않는다.
5. **측정 우선**: 성능 항목은 착수 전 기준선 수치를 `docs/benchmarks/`에 남긴 뒤 시작.
6. **회귀 방지**: 수정 대상 영역에 특성화 테스트를 먼저 추가한다.
7. **`newspin-ai`는 변경하지 않는다.** BE↔AI 계약 변경이 필요하면 BE 쪽에서 흡수하거나 별도 합의.
8. 커밋/PR 트레일러: `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>`, PR 본문에 생성 표기.

## 결과

- 진행 현황은 `docs/README.md` 표에서 한눈에 본다.
- 각 PR은 대응 문서 링크를 본문에 포함한다.
